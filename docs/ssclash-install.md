# SSClash: установка SSClash-Go или SSClash 4

Памятка: как поставить SSClash на OpenWrt без доступа к GitHub на
роутере — на выезде, без ПК и без VPN.

> **Статус: в разработке.** SSClash 4 ставится из зеркала и работает
> без VPN. SSClash-Go зависит от доступа к GitHub: бесплатные прокси
> сейчас слишком медленные (сотни байт в секунду), поэтому для установки
> на выезде надёжнее установщик с ПК (`ssclash/install.bat`) или будущее
> приватное зеркало с токеном.

Скрипт: `scripts/install-ssclash.sh` (личный, в README не афишируется).

## Две версии

| | SSClash-Go | SSClash 4 |
|---|---|---|
| Интерфейс | веб на `:9091` | LuCI → Services → SSClash |
| Пакет | один бинарник | `luci-app-ssclash` |
| Лицензия | закрытая, перепубликация запрещена | GPL-2.0 |
| Откуда ставится | официальные ссылки через зеркала-прокси | зеркало в этом репозитории |

Обе версии используют один каталог `/opt/clash`, поэтому **вместе они
не работают**. Скрипт это видит и предлагает удалить текущую версию
перед установкой другой.

## Автоопределение

Ничего указывать не нужно:

- читается `/etc/openwrt_release`;
- `23.05` и `24.10` → `opkg` и `.ipk`;
- `25.12` → `apk` и `.apk`;
- архитектура — `aarch64` → `arm64` (пока только она);
- проверяется, что уже установлено: Go (`/opt/clash/bin/ssclash`,
  `/etc/init.d/ssclash`) или SSClash 4 (`luci-app-ssclash`).

## Запуск

```sh
wget -O /tmp/install-ssclash.sh https://raw.githubusercontent.com/k4reon/k4reon-mihomo-rules/main/scripts/install-ssclash.sh && sh /tmp/install-ssclash.sh
```

Главное меню:

```
========================================
 SSClash: установка и обновление
========================================

Что установить?
  1) SSClash-Go — новая версия, веб-интерфейс :9091
  2) SSClash 4 — LuCI, Services → SSClash
  3) Память — лимиты GOGC / GOMEMLIMIT для mihomo
  0) Выйти
```

Для SSClash-Go:

```
  1) Установить всё (клиент + ядро)
  2) Установить только клиент
  3) Обновить только клиент
  4) Установить только ядро
  5) Обновить только ядро
  6) Проверить состояние
  7) Удалить SSClash-Go
  8) Обновить профили конфигурации
  0) Назад
```

При установке только ядра предлагается версия:

```
Выберите ядро Mihomo:
  1) v1.19.24 — 31,9 МБ (база)
  2) v1.19.25 — 41,1 МБ (+ Tailscale, OpenVPN, GOST)
  3) v1.19.30 — 44,4 МБ (+ ZeroTier, AmneziaWG)
  4) v1.19.31 — 54,6 МБ (+ EasyTier)
  5) v1.19.34 — 54,7 МБ (последняя)
  0) Отмена
```

### Что меняет каждый пункт

| Пункт | Меняет | Не трогает | Проверка версии |
|---|---|---|---|
| 1) всё | клиент, init-скрипт, профили, пароль (если не задан), ядро | — | клиент + ядро |
| 2) только клиент | клиент, init-скрипт, профили | ядро | клиент + профили |
| 3) обновить клиент | клиент, init-скрипт | профили, `config.yaml`, пароль, ядро | клиент |
| 4) только ядро | ядро | всё остальное | выбранное ядро |
| 5) обновить ядро | ядро | всё остальное | ядро |
| 8) обновить профили | `/opt/clash/configs/*.yaml` (+ `.bak`), `config.yaml` — только если его не правили | клиент, ядро, пароль | содержимое файлов (сверка с репозиторием) |

Профиль, в котором вместо заглушки указана **своя подписка**, не
перезаписывается: скрипт проверяет `url` в блоке `proxy-providers`
и пишет «содержит свою подписку — не перезаписываю». То же правило
действует при установке клиента (пункты 1–2).

У SSClash 4 проверка такая же: пункт 1 сверяет версию пакета и ядра,
пункт 2 — только ядра.

Перед каждым действием скрипт печатает, что изменится. Пароль
веб-интерфейса не запрашивается, если он уже задан, — обновление
клиента его не сбрасывает.

Скрипт сверяет установленную версию с целевой **в каждом пункте
установки и обновления**. Если они совпадают, он ничего не качает и
пишет, например: «SSClash-Go 7.7.2 и ядро v1.19.34 уже установлены —
обновление не требуется». Переустановить ту же версию можно так:

```sh
sh /tmp/install-ssclash.sh --go --client-update --yes --force
sh /tmp/install-ssclash.sh --go --core --yes --force
```

в меню — пункт 3 или 5 и ответ `y` на вопрос о принудительной
переустановке.

Если на роутере стоит SSClash 4, скрипт не удаляет его молча: он
показывает предупреждение и требует ввести `yes`. Это происходит
только при установке SSClash-Go (пункты 1–2), но не при обновлении
клиента или ядра.

Для SSClash 4:

```
SSClash 4
  версия: 4.7.1, целевое ядро: v1.19.34
  пакет: 4.7.1-r1 (установлен)   | не установлен
  ядро: v1.19.34                 | не установлено
  SSClash-Go 7.7.2 — будет удалён при установке SSClash 4

  1) Установить / обновить
  2) Обновить только ядро Mihomo
  3) Проверить состояние
  4) Удалить SSClash 4
  0) Назад
```

`0` в подменю возвращает в главное меню; `0` в главном меню — выход
из скрипта.

## Удаление

Удаление требует ввести `yes` — и для SSClash-Go, и для SSClash 4.
Каталог `/opt/clash` (конфиг, профили, ядро) удаляется только
отдельным подтверждением; в неинтерактивном режиме — только с
флагом `--purge`:

```sh
sh /tmp/install-ssclash.sh --go --uninstall --yes          # конфиг остаётся
sh /tmp/install-ssclash.sh --go --uninstall --yes --purge  # удалить всё
```

## Без вопросов

```sh
sh /tmp/install-ssclash.sh --go --yes            # SSClash-Go целиком
sh /tmp/install-ssclash.sh --go --client --yes   # только клиент
sh /tmp/install-ssclash.sh --go --client-update --yes  # обновить клиент
sh /tmp/install-ssclash.sh --go --core --yes     # только ядро (v1.19.34)
sh /tmp/install-ssclash.sh --go --core --core-version v1.19.24 --yes
sh /tmp/install-ssclash.sh --go --yes --web-password 'Пароль123'
sh /tmp/install-ssclash.sh --ss4 --yes           # SSClash 4
sh /tmp/install-ssclash.sh --status              # состояние
sh /tmp/install-ssclash.sh --profiles            # обновить профили конфигурации
sh /tmp/install-ssclash.sh --memory              # лимиты памяти, с вопросами
sh /tmp/install-ssclash.sh --memory --yes        # лимиты памяти без вопросов
sh /tmp/install-ssclash.sh --dry-run --go        # только план
sh /tmp/install-ssclash.sh --ss4 --uninstall     # удалить
sh /tmp/install-ssclash.sh --go --uninstall --yes --purge  # удалить с конфигом
```

## Память

Пункт `3` в главном меню (или `--memory`) скачивает
`scripts/memory-limit.sh` и запускает его: скрипт сам определяет
SSClash-Go или SSClash 4, показывает объём ОЗУ, предлагает `GOGC` и
`GOMEMLIMIT`, делает бэкап init-скрипта в `.bak` и перезапускает службу.

- `--memory` — интерактивно (применить / свои значения / откатить);
- `--memory --yes` — сразу применить рекомендуемые;
- `--dry-run --memory` — только показать, что будет добавлено.

Отдельный скрипт остаётся доступен сам по себе — он же описан в
README: `wget -O /tmp/memory-limit.sh .../scripts/memory-limit.sh && sh /tmp/memory-limit.sh`.

## Откуда качается

**SSClash 4** — из зеркала `third_party/ssclash4/`:

1. jsDelivr;
2. raw.githubusercontent;
3. github.com/raw;
4. официальный релиз.

Файлы не изменены, `sha256` проверяется.

**SSClash-Go** — только официальные ссылки, но с обходом недоступного
GitHub:

1. `github.com/zerolabnet/SSClash-Go/releases/...`;
2. `ghproxy.net`;
3. `gh-proxy.com`;
4. `ghfast.top`.

Свойства:

- версии зашиты в скрипт: Go `7.7.2`, ядро по умолчанию `v1.19.34`;
- при установке только ядра можно выбрать 1.19.24 / 1.19.25 / 1.19.30 /
  1.19.31 / 1.19.34;
- `sha256` клиента, init-скрипта и ядра проверяется обязательно;
- перепубликации нет — лицензия SSClash-Go это запрещает.

**Ядро Mihomo** — с официального релиза MetaCubeX через те же прокси.

## Установка и замена ядра

Порядок для обеих версий:

1. скачать во `/tmp`;
2. проверить `sha256`;
3. остановить службу и остатки ядра (иначе `Text file busy`);
4. распаковать новое ядро во временный файл, проверить `-v`;
5. **проверить, что новое ядро принимает текущий `config.yaml`**
   (`clash.new -t -d /opt/clash`) — если нет, установка отменяется,
   старое ядро остаётся нетронутым (`--force` обходит проверку);
6. заменить `/opt/clash/bin/clash`;
7. запустить службу (для Go) или оставить выключенной (для SSClash 4).

Копия старого ядра (`clash.old`) **не создаётся**: совместимость
проверяется до замены, а откатиться всегда можно, установив прежнюю
версию через «Установить только ядро». При обновлении ядра старые
копии (`clash.old`, `clash.v*.bak`) удаляются.

Обновление **только ядра** требует всего ~3 МБ свободной флеши: файл
качается в `/tmp` (tmpfs) и заменяется на месте. Обновление клиента
требует ~20 МБ.

Копия предыдущего клиента (`ssclash.<версия>.bak`) хранится в одном
экземпляре: при следующем обновлении старая копия удаляется. Если
версия не менялась, копия не создаётся.

SSClash 4 после установки остаётся выключенным: открой LuCI →
**Services → SSClash**, проверь настройки и запусти.

## Профили конфигурации

При установке SSClash-Go (пункты 1–3) в `/opt/clash/configs/` кладутся
четыре профиля:

| Профиль | Что это |
|---|---|
| `full-proxy` | полный PROXY (`MATCH,PROXY`) |
| `full-direct` | полный DIRECT (`MATCH,DIRECT`) |
| `lite-proxy` | lite-PROXY без GEOIP/geosite |
| `lite-direct` | lite-DIRECT без GEOIP/geosite |

Если `/opt/clash/config.yaml` ещё нет, активным становится **`lite-direct`**:
он копируется в `config.yaml`, а в `.ssclash/active-profile` пишется
`lite-direct`. Если конфиг уже существует, он и активный профиль
не меняются — новые профили просто добавляются.

Подписка во всех профилях — заглушка
`https://example.com/your-subscription`, её нужно заменить вручную
в каждом профиле, которым будешь пользоваться.

## После установки SSClash-Go

Скрипт спрашивает пароль веб-интерфейса (минимум 8 символов) и сам
создаёт его. **Ядро при этом не запускается** — после установки работает
только веб-служба `ssclash`, а Mihomo стартует вручную кнопкой **Start**
в интерфейсе. В конце печатается реальный адрес:

```
Готово: SSClash-Go 7.7.2, ядро v1.19.24.
Веб-интерфейс: http://192.168.7.1:9091
Ядро: не запущено. Нажмите Start в веб-интерфейсе.
```

Если ставили **только клиент** (без ядра), вывод будет:

```
Готово: SSClash-Go 7.7.2, ядро не установлено.
Веб-интерфейс: http://192.168.7.1:9091
Ядро: не установлено. Установите пунктом 4.
```

Если автоматическая настройка не удалась (например, сломан `curl`),
скрипт пишет об этом и оставляет адрес. Тогда открой его вручную, задай
пароль и нажми **Start**. Для настройки используется `wget` с cookies,
`curl` — только запасной вариант.

## Переключение версий

Если установлена одна версия, а ставится другая, скрипт пишет:

```
Установлен SSClash-Go. Вместе с SSClash 4 они не работают.
Удалить SSClash-Go и продолжить? [y/N]
```

При `y` удаляется клиент и служба прежней версии, `/opt/clash`
с конфигом сохраняется. С `--yes` подтверждение не спрашивается.

## Удаление

- Go: останавливается служба, удаляются `/etc/init.d/ssclash` и
  `/opt/clash/bin/ssclash`;
- SSClash 4: удаляется пакет `luci-app-ssclash` и init-скрипт;
- отдельно спрашивается, удалять ли `/opt/clash` (конфиг, подписки,
  ядро).

## Если файлы уже скачаны на ПК

```sh
sh /tmp/install-ssclash.sh --go --yes --from /tmp/ssclash-files
```

В каталоге должны лежать:

- `ssclash-linux-arm64`
- `ssclash-openwrt-service.tar.gz`
- `mihomo-linux-arm64-v1.19.34.gz`

Для SSClash 4 — пакет `.apk`/`.ipk` под свою ветку.

## Проверено

- GL.iNet GL-MT6000, OpenWrt 25.12.5, `aarch64_cortex-a53`, `apk`;
- `--status`: определены обе версии, ядро `v1.19.34`, службы
  различаются корректно;
- `--dry-run --go` и `--dry-run --ss4`: показывают план и
  предупреждение о конфликте, ничего не меняют;
- `--go --uninstall --dry-run`: показывает план удаления.
